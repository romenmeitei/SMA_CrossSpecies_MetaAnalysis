# Data directory

Large public-source inputs and generated matrices are not tracked in Git.

Dataset accession numbers, eligibility, biological roles and source locations
are recorded in `config/dataset_manifest.csv`.

For the exact frozen analysis inputs and processed files, download the
versioned reproducibility archive from the GitHub Releases page.

The repository does not redistribute large external platform files, FASTQ
files or third-party resources when retrieval from the authoritative source
is more appropriate.
